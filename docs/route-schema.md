# route.json — schema `happyfeet.route/1`

One excursion: the map draws it, the survival card prices it, the VR page replays it and the
integrity manifest signs it. Produced by `web/route-io.js` (`buildRoute`), validated by `parseRoute`.
Demo file: `web/public/data/route.json` (generated by `scripts/make-demo-route.mjs` with the same
router and survival model as the page). In the app: **Path** tab → *Load demo excursion*, or compute a
route and press **⬇ route.json**; *Open route.json…* loads one back.

| Field | Type | Meaning |
|---|---|---|
| `schema` | string | always `"happyfeet.route/1"` |
| `generated_at`, `generator` | string | ISO time; what produced the file |
| `site`, `label` | string | human labels |
| `profile` | object | `mobility`, `scenario` (key of `SCENARIOS` in `survival.js`), `max_slope_deg`, `grid_level`, `terrain_source` |
| `crew[]` | object | `id`, `name`, `body_mass_kg`, `metabolic_scale`, `o2_kg`, `water_kg`, `battery_wh` (usable capacities) |
| `params` | object | every coefficient used (see `docs/assumptions.md`) |
| `waypoints[]` | object | `name`, `role` (`haven` \| `science`), `lon`, `lat` (deg, planetocentric, east-positive), `index` into `path` |
| `path[]` | object | `lon`, `lat`, `elevation_m` (m, MOLA areoid) — the planned polyline, haven first |
| `distance_m`, `eta_s` | number | whole excursion including the return leg and sampling time |
| `timeline[]` | object | `name`, `index`, `t_s` (arrival time), `dist_m`, `dwell_s` |
| `blackout[]` | object | runs of path points with no line of sight to the haven antenna: `from`, `to` (path indices), `duration_s`, `from_m`, `to_m` |
| `warnings[]` | object | `level` (`refuse` \| `warn`), `code`, `text` |
| `survival` | object | `feasible`, `verdict`, `limiting` (crew + consumable with the lowest reserve), `crew[]` (`used`, `reserve` fractions at return, `walk_back` {index, dist_m}, `tightest` margin, `failure`), `risk_cost_s`, `return_leg` |
| `reports[]` | array | crew field reports (reserved, empty for now) |
| `terrain` | object | local height grid: `bounds` {west,south,east,north}, `cols`, `rows`, `heights[]` (row-major, row 0 = north, `null` = no data), `width_m`, `height_m`, `source`, `note` |
| `honesty[]` | string | limitations that must travel with the file |

Rules: angles in degrees, distances in metres, times in seconds. A loaded file is re-evaluated by the
page's own survival model (the stored `survival` block is what the generator computed). A route
computed live in the browser is **not signed** — only files listed in the signed manifest are.
